# Widget: ConversationItem

## Objetivo

Construir un componente reutilizable que represente una conversación en una lista de chats.

## Componentes utilizados

- Row
- CircleAvatar
- Expanded
- Column
- Text
- Icon

## Parámetros

- image
- name
- message
- time
- status

## Resultado

El widget puede reutilizarse para cualquier conversación simplemente cambiando los datos enviados al constructor.
