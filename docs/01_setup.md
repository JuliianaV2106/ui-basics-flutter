# Configuración del proyecto

## Objetivo

Crear la estructura inicial del proyecto Flutter siguiendo buenas prácticas de organización.

## Actividades realizadas

- Creación del proyecto Flutter.
- Inicialización del repositorio Git.
- Organización de carpetas.
- Configuración para separar pantallas y widgets reutilizables.

## Resultado

El proyecto quedó preparado para comenzar el desarrollo de componentes reutilizables.
