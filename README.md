# UI Basics con Flutter

## Autor

Juliana Valencia

## Descripción

Este proyecto implementa las interfaces propuestas en el laboratorio "UI Basics con Flutter".

El objetivo es aprender la construcción de interfaces mediante componentes reutilizables utilizando StatelessWidget.

## Pantallas

- Login
- Register
- Profile

## Componentes

- Conversation Item
- Statistic Item
- Statistics Row
- Profile Info
- Profile Card
- Conversation List

## Tecnologías

- Dart
- Material Design
- Git
